# Trius LLC — site guide for Claude

Marketing site for Trius LLC, a medical courier (STAT + scheduled routes) in the Pacific Northwest.

## Stack

- **Astro 5**, `output: 'static'`, deployed on **Netlify** (`netlify.toml` holds redirects and headers).
- **Tailwind 3** via `@astrojs/tailwind` (`applyBaseStyles: false`; base/components live in `src/styles/globals.css`).
  Brand palette is in `tailwind.config.js` (`primary` #0e70a4 Trius Blue, `secondary` green, `accent` red).
  daisyUI is installed and `<html data-theme="trius">` is set, but no daisyUI plugin is registered in the Tailwind config.
- **Sanity is optional.** `src/utils/sanity-client.ts` falls back to a placeholder project id, and the site builds
  with no `.env` (see `.env-sample`). Header/footer use hardcoded fallbacks in `src/layouts/Layout.astro`.
- Fonts: Inter from Google Fonts (`Layout.astro`), Orbitron 900 self-hosted via `@fontsource` (only `font-black` is used).

## Commands (pnpm)

| Command        | What it does                                              |
| -------------- | --------------------------------------------------------- |
| `pnpm dev`     | Dev server on http://localhost:3000                       |
| `pnpm build`   | `astro build` to `dist/`                                  |
| `pnpm preview` | Serve `dist/` locally                                     |
| `pnpm lint`    | ESLint over `src/` (`lint:fix` to autofix)                |
| `pnpm format`  | Prettier over the repo (`format:check` in CI-style)       |

## Project map

- `src/pages/` — `index`, `about`, `coverage`, `contact`, `services` (+ `services/stat-delivery`, `scheduled-routes`,
  `specialized-equipment`), `privacy`, `terms`, `thanks`, `404`.
- `src/layouts/Layout.astro` — global `<head>` (SEO/OG/canonical, manifest, theme-color), skip link, header/footer, nav fallback data.
- `src/components/` — page sections (Hero, TrustSection, Testimonial, Cta, Card, etc.), `Header`/`Footer`, `InteractiveCoverageMap`.
- `src/lib/schema.ts` — JSON-LD `@graph` (Organization/LocalBusiness/Service etc.) rendered via `astro-seo-schema`.
- `src/data/` — `siteConfig.js`, `page.js`, `blocks.js`, `seoContent.ts`; `contact.ts` is the single source of truth for
  NAP/contact data (phone, email, address) — never hardcode those elsewhere.
- `src/utils/` — `markdown.ts` (marked + DOMPurify; always sanitize `set:html`), `sanity-client.ts`.
- `public/llms.txt`, `public/llms-full.txt` — LLM-facing site summaries; keep in sync with copy changes.
- `public/states/coverage-states.json` — boundaries for the coverage map (see below).
- `AUDIT_TASKS.md` — running audit checklist; open work is tracked there.

## Conventions

- **Images** live in `public/Images/` as kebab-case **WebP**, max 1920px wide. Hero images get a
  `<link rel="preload" as="image">` in the page's `head` slot. Root-level `og-image.png`, `handoff.webp`, `kevin_profile.webp`.
- **Icons** use `astro-icon`: `<Icon name="heroicons:..." />` (integration in `astro.config.mjs`). No runtime Iconify.
- **Coverage map** (`src/components/InteractiveCoverageMap.astro`) uses **bundled Leaflet** (`import L from 'leaflet'`
  + its CSS, no CDN). It fetches `public/states/coverage-states.json`, generated by
  `node scripts/filter-coverage-geojson.mjs <full-census-geojson>` — rerun it if the coverage states change and keep
  `COVERAGE_STATES` in that script matched to the component's `coverageData` keys.
- **Sitemap**: `@astrojs/sitemap` in `astro.config.mjs` sets per-page priority in `serialize`; do not add `lastmod`
  (it would stamp every URL with the build time on each deploy).
- **Security headers / CSP** are in `netlify.toml`; add any new third-party origin to the relevant CSP directive.
  Long-lived caching is set for `/_astro/*` (immutable) and 30 days for static media.
- Accessibility: keep the skip link + `<main id="main-content">` in `Layout.astro`; landmarks carry `aria-label`s.
- Formatting: Prettier (`.prettierrc`: 4-space indent, single quotes, 160 cols / 140 for `.astro`, `prettier-plugin-astro`).
  Don't reformat unrelated files.
